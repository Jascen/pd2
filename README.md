# pd2

Quick-reference pages for Project Diablo 2, hosted with GitHub Pages.

| Page | File |
| --- | --- |
| Pathing Compass: which direction to explore in every zone | `pathing.html` |
| Reset Sheet: act-by-act group reset plan with mutable columns | `reset.html` |

## Adding a page

1. Add a self-contained `your-page.html` at the repo root.
2. Add an entry to the `PAGES` list in `index.html`.
3. Commit and push to `main`; Pages redeploys automatically.

Pathing data condensed from the [Hiim PD2 Pathfinding Guide](https://hiimpd2.com/pathfinding), adapted from Knoofle's PD2 Pathfinding Guide. Not affiliated with Blizzard Entertainment or the Project Diablo 2 team.
